# Проверка развёртывания

Проверено 2 октября 2026 года на `192.168.10.5`: Debian 13, непривилегированный LXC, 2 CPU, 2 ГБ RAM.

## Автоматические проверки

- `go test ./...` — пройдено: страницы, роли, запрет доступа к чужим решениям, сокрытие тестов, CSRF, вход и cookies, сроки контеста, версии, лимит отправок, ZIP-валидация и сравнение ответов.
- `go vet ./...` — без замечаний.
- `bash -n deploy/install.sh` — корректный синтаксис.
- Интеграционные тесты на сервере, от пользователя `contests`: Python AC, C++17 AC, WA, RE, CE, TLE по CPU, TLE по реальному времени, MLE, OLE, недоступность сети и файлов приложения — пройдено.

## Браузер

Проверено в Chromium через настоящий HTTP-интерфейс:

1. Вход администратора и создание учителя.
2. Вход учителя, создание ученика, опубликованного контеста и задачи.
3. Добавление и удаление строк примеров/тестов.
4. Экспорт задачи в ZIP и обратный импорт.
5. Отправка учеником Python-решения, автоматическое обновление статуса, 100/100.
6. Запрет кабинета учителя для ученика.
7. Таблица результатов учителя и повторная проверка отправки.
8. Сохранение исходной версии задачи у старой отправки после редактирования.
9. Загрузка C++-решения файлом, 100/100.
10. Мобильная ширина 390 px — без горизонтального переполнения, ошибок JavaScript не обнаружено.

## Эксплуатация

- При перезапуске worker тестовая отправка `RUNNING` снова проверена и получила `AC`, 100 баллов.
- `PRAGMA integrity_check` вернул `ok`; `foreign_key_check` не нашёл нарушений.
- Nginx и три службы приложения/песочницы активны. Автозапуск включён.
- Веб-служба слушает только `127.0.0.1:8080`. Внешняя точка входа — Nginx на порту 80.
- После тестов веб-служба использовала около 11 МБ, worker — около 4 МБ по `MemoryCurrent` systemd. Это измерение в покое, не оценка пика компиляции или максимальной нагрузки.
- Искусственные аккаунты и контест удалены. Их копия на сервере: `/var/backups/contests/pre-smoke-cleanup.db`, доступ только root. Рабочая база содержит администратора и начальный контест.

Сайт пока предназначен для локальной сети и работает по HTTP. Нагрузочное тестирование на большом классе, внешнее HTTPS и автоматическое резервное копирование не выполнялись.
