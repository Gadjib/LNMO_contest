# Контест одним ZIP · версия 1

Учитель может подготовить весь контест вне сайта и загрузить его одним архивом. На странице «Контесты» нажмите **«Загрузить ZIP»**, выберите файл и нажмите «Загрузить контест». После успешного импорта откроются настройки нового контеста. Проверьте даты и классы, затем отметьте «Опубликовать контест» и сохраните.

Импорт всегда создаёт **новый черновик**, не заменяет существующие контесты и не переносит учеников или отправки. При любой ошибке ни контест, ни его задачи не сохраняются. Повторный успешный импорт создаёт ещё один контест.

## Структура архива

```text
contest.zip
├── contest.yaml
└── problems/
    ├── A/
    │   ├── problem.yaml
    │   ├── tests/
    │   │   ├── 01.in
    │   │   └── 01.out
    │   └── assets/
    │       └── diagram.png
    └── B/
        ├── problem.yaml
        └── tests/
            ├── 01.in
            └── 01.out
```

`contest.yaml` лежит непосредственно в корне ZIP, без внешней папки. Внутри — папки задач, **не вложенные ZIP-архивы**. `assets/` нужен только для задач с изображениями.

## contest.yaml

```yaml
format_version: 1
title: "Тренировочный контест"
description: |
  Две задачи на арифметику.
starts: "2026-10-15T15:00:00+03:00"
ends: "2026-10-22T18:00:00+03:00"
classes:
  - "8м"
  - "9м"
problems:
  - problems/A
  - problems/B
```

| Поле | Правила |
|---|---|
| `format_version` | Обязательно `1`. |
| `title` | Обязательно, непустое название до 300 байт UTF-8. |
| `description` | Необязательно, Markdown, до 100 000 байт. |
| `starts`, `ends` | Обязательные даты RFC3339 с часовым поясом. `+03:00` — московское время. Окончание позже начала. Даты в кавычках. |
| `classes` | Список доступных классов, до 100. `classes: []` или отсутствие поля — все ученики, включая учеников без класса. Регистр и лишние пробелы нормализуются. Классы могут ещё не иметь учеников. |
| `problems` | От 1 до 50 уникальных путей вида `problems/A`. Порядок списка задаёт порядок задач на сайте. Имя папки: 1–40 латинских букв, цифр, `_`, `-`, первый символ — буква или цифра. |

Неизвестные поля и несколько YAML-документов запрещены. Поля `published` нет: публикация выполняется вручную на сайте. Ограничения по классам не распространяются на учителей и администраторов.

## Задачи

В каждой папке обязателен `problem.yaml`. Его формат **не меняется**: [полное описание задачи](task-format.md). Коды `code` всех задач внутри контеста должны быть уникальными; имя папки может отличаться от `code`.

Пути в `input_file`, `answer_file` и Markdown-картинках отсчитываются **от папки своей задачи**, а не от корня контеста:

```yaml
statement: |
  Найдите число рёбер графа.
  ![Граф](assets/diagram.png)
# Остальные обязательные поля задачи — в task-format.md.
tests:
  - id: "01"
    input_file: tests/01.in
    answer_file: tests/01.out
    points: 100
```

Ссылки на внутренние `/images/...` вместо файлов не допускаются. Экспорт сайта сам упаковывает изображения в `assets/`.

## Ограничения

- ZIP и его суммарное распакованное содержимое — до **20 МБ на весь контест**.
- Каждый файл — до 1 МБ; до 11 251 записи в ZIP.
- Для каждой задачи сохраняются прежние ограничения: до 100 тестов, до 16 МБ тестовых данных, до 20 картинок общим размером до 3 МБ. Общий лимит контеста имеет приоритет.
- Текстовые файлы — UTF-8. Абсолютные пути, `..`, обратные слеши, символьные ссылки, повторяющиеся имена и файлы вне перечисленных папок задач запрещены.
- Архив не распаковывается на серверный диск.

## Готовый пример

В [examples/contest](../examples/contest/) есть полностью готовый контест с двумя задачами. Из корня репозитория:

```bash
cd examples/contest
zip -r /tmp/contest-example.zip contest.yaml problems
```

Загрузите `/tmp/contest-example.zip`, проверьте даты и опубликуйте. Пример предназначен для демонстрации формата; для реального соревнования добавьте более полный набор тестов.

## Экспорт

На странице контеста учителю доступна кнопка **«Скачать контест ZIP»**. Архив содержит настройки, текущие версии всех задач, тесты и картинки. История версий, аккаунты, решения учеников и результаты не экспортируются. Импорт экспортированного архива создаст отдельный черновик с теми же сроками и ограничениями по классам.

Старые ZIP одной задачи по-прежнему загружаются через редактор задачи, а не через импорт контеста.
